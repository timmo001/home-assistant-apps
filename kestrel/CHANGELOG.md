Kestrel now shows which version you're on: beside its name in the app bar, and in more detail at the end of Settings.

## App

- The app bar shows Kestrel's version beside its name, so you can tell at a glance which release a browser, the desktop app or Home Assistant is running.
- Settings ends with an About card: this page's version and when it was built, the server it's talking to with its version and id, and a Release notes button for the version you're on. Where the server runs another version than the page, it says so.
