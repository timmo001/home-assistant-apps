## Jobs

- The attention job only marks your own pull request ready to merge when you have the right to merge it on that repository and no required review is still to come. Pull requests on repositories where a maintainer reviews or merges them no longer show as yours to merge.

## Server

- An approval on its own no longer puts your pull request under Needs you; it needs to be ready to merge as well. Approved pull requests a maintainer still has to merge wait with the rest of your work instead.
