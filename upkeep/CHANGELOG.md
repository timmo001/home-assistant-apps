## App

- The triage options now say where their values come from. The host token comes from `triage hosts add upkeep` and the admin token from `triage admins add upkeep`, rather than triage's server admin token. The triage URL says that leaving it empty uses the triage app from the same repository. Before, it said leaving it empty turned triage off, which stopped being true in 0.1.10.
- The app's docs describe the same setup.

No changes to the server, dashboard or workers.
